# Compte Rendu post-réunion de la semaine (14/03)

## Héritage avec EpisodicAlgo et EpochBasedAlgo
  - **EpisodicAlgo** : 
	- Utilisé pour les algorithmes qui utilisent le mode `autoreset=False` donc chaque env attend que tous les autres aient fini leur épisode pour passer à l'épisode suivant.
- **EpochBasedAlgo** : 
	- Utilisé pour les algorithmes qui utilisent le mode `autoreset=True` donc chaque env se réinitialise dès qu'il a fini son épisode et implémente directement le ReplayBuffer pour la répartition iid des données.

## Tensorboard
Utile pour visualiser les courbes d'apprentissage des différents algorithmes avec comme principal indicateur la reward. Attention à ne pas lisser les courbes et ne pas enlever les outliers pour ne pas fausser l'interprétation des résultats.
